## DSH 安装与卸载

Node.js 22+，目标 DSH 服务须满足 TGZ 中声明的 peer 范围。在项目根目录执行或替换为解压后实际路径：

```powershell
dsh plugin --profile web add 'D:/mycode/agent-docs/dsh-agent-docs-0.1.6.tgz'
dsh plugin --profile web remove dsh-agent-docs
```

不要连续执行两条，第二条仅在卸载时使用。--offline 只有整个 Profile 的依赖缓存齐全时适用。安装后重启对应实例，确认 agent_docs_rules 工具可用，info 的 rulesDir、init、maintain 均指向包内 defaults。

卸载后检查依赖及 bundle 条目消失，真实 Cordis 宿主卸载后工具与监听失效；包管理器共享缓存可以保留，不视为插件额外写入。

## Codex 安装与卸载

解压 codex-agent-docs-0.1.6.zip，PowerShell 执行（替换解压目录）：

```powershell
& '<解压目录>/install-codex.ps1'
codex plugin add codex-agent-docs@personal-local --json
codex plugin list --marketplace personal-local --json
node "$env:USERPROFILE/.codex/plugins/local/codex-agent-docs/scripts/rules-cli.mjs" info
```

确认 version=0.1.6、installed=true、enabled=true。规则路径必须是包内 defaults。桌面应用重启后新建聊天；Hook 升级可能需要重新审阅，安装脚本不会伪造信任记录。

完整卸载：

```powershell
codex plugin remove codex-agent-docs@personal-local --json
& '<解压目录>/uninstall-codex.ps1'
```

原生命令移除安装缓存与启用状态；清理脚本移除登记用源及本插件市场条目，保留共享市场和其他插件。脚本不会额外制造备份。显式自定义目录不会被卸载删除。

install/uninstall 脚本支持 -UserRoot 指定独立测试根目录，仅用于隔离脚本的生命周期测试；日常使用不传此参数。不要把测试登记误当成桌面客户端安装。

## 规则定位与自定义

默认不需要同步。显式设置 DSH rulesDir 或环境变量 AGENT_DOCS_RULES_DIR 才启用自定义目录，必须是绝对路径。DSH rulesDir 优先。环境变量改变后需重启宿主，规则正文改变下次读取生效。旧版 ~/.agent-docs 不会默认读取。

## 验证边界

自动检查覆盖归档清单、包内四规则与源码一致、解压后的 Hook 子进程、规则默认更新与显式自定义保护、真实 Cordis 工具和监听卸载。安装后还需单独核对版本、实际返回路径和宿主外目录是否产生。

以下语义行为需真实模型观察，自动测试或安装回读不能代替：

1. 普通无 Docs 轮次不自动初始化。
2. 显式初始化创建四核心目录及索引，其他文件按需创建，验证材料约定在根目录 evidence/ 或项目已有位置。
3. 同一 Agent 正常轮次只提醒一次；续接后放行，用户禁改时不修改。
4. 对照有效 Design 或用户要求核验，Project 反映实现和验证边界，不强制生成 Spec/任务清单。
5. 逐层索引可达且只概括直接子级，外部集合、主题引用与临时证据入口各有适当位置。
6. 稳定项目偏好可提炼，冲突和扩大范围需确认，不自动跨项目推广。

出现失败应记录实际版本、规则路径、输入与观察结果，不将配置展开、路径检查标为模型闭环通过。
