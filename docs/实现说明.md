# 实现说明

Agent Docs 由独立的 DSH 与 Codex 插件组成。插件不推理、不直接写项目 Docs，也不创建第二个 Agent；原 Agent 读取规则、判断并按需编辑。

0.1.5 仅调整默认规则及配套说明，运行时触发机制不变。规则将 Docs 定位为人和 AI 共享的持久上下文，首次初始化默认四核心目录，其他内容按需单文件；验证材料无既有约定时放项目根目录 evidence/。索引只对直接子级逐层概括，向上仅修正失准摘要；稳定项目偏好允许主动提炼，冲突和扩大范围需确认。既有用户规则和项目目录不自动升级或迁移。

- `rules/`：唯一默认规则源，包含用户修改的 `init.md`、`maintain.md`，以及其依赖的 `principles.md`、`spec.md`。构建时四份一起复制到两个插件 `defaults/`，首次调用补齐缺失的引用文件。
- `src/rules.mjs`：配置定位、只在缺失时创建用户文件、可读性检查及默认回退。
- `plugins/dsh-agent-docs/src/index.mjs`：Cordis 模块，声明依赖 `agents`、`tools`；监听 `agent/turn-stopping`，按 Agent 弱引用和 turn 去重，再 `steer(createUserMessage(...))`。过滤 `origin=subagent` 或深度大于零的 Agent，普通聊天 fork 不因有 parentSession 而被误排除。
- `plugins/codex-agent-docs/scripts/stop.mjs`：同步 Stop 命令，输入事件为 Stop、stop_hook_active 为 false 且 cwd 有 docs/index.md 才返回 block + reason。其他输入与异常返回 `{}`。
- Codex `skills/init` 和 `skills/rules`：显式初始化及规则查看/编辑入口。DSH 对应入口为 `agent_docs_rules` 工具。

规则默认位于 `~/.agent-docs/dsh`、`~/.agent-docs/codex`。DSH 配置 `rulesDir` 优先于环境变量 `AGENT_DOCS_RULES_DIR`，后者适用于两端。路径必须绝对。已有用户内容不自动合并或覆盖，规则每次调用重新检查并由 Agent 读取，异常时使用随包默认文件或放行原任务。

DSH 显式初始化/维护工具调用后跳过本轮自动检查；Codex 初始化技能要求在 Stop 续接时直接结束，可能仍收到一次冗余提醒，不承诺整个初始化轮次完全不触发 Hook。Codex 去重依赖宿主 `stop_hook_active`；与多个 Stop Hook 的组合需桌面验收。

日常检查只识别当前 cwd 的 Docs 入口，不向上扫描磁盘或推断 Git 根目录。用户应在项目根目录使用；在子目录会跳过维护。Hook 不以 Git diff 或关键词决定是否需要更新。

版本约束按本机 DSH 0.2.2-rc.1、Cordis 4.1.0、Schemastery 3.19.0 核对；本地源码检出的 package.json 仍标为 0.1.3-alpha.2，因此实际已安装类型与运行包优先。升级 DSH 后应重新核对 peer 范围，不能靠版本豁免强装。
